# Смета в PDF (RENTAL HUB)

Статический сайт на GitHub Pages: загружаешь Excel → получаешь оформленный PDF A4. Сборки и сервера нет, каждая версия — один самодостаточный HTML-файл.

- `index.html` — версия 1 (https://easyshm-png.github.io/PDF/). Два режима: «Смета аренды» и «КП с фото».
- `v2/index.html` — версия 2 (https://easyshm-png.github.io/PDF/v2/), строгий фирменный дизайн, только смета.

Правки делаются прямо в этих файлах, коммит в `main` — сайт обновится сам через 1–2 минуты.

## Что где внутри index.html

Первый `<script>` (глобальный):
- `var FONTS={...}` — встроенные шрифты Inter (TTF base64 + карты глифов). Большая строка, её не трогать.
- `function buildPdf(model,opt,F)` — генератор PDF без библиотек (векторный текст, A4). Внутри: `header()` (шапка сметы), `kpHeader()` и `kpBody()` (режим КП), `section()`, `totals()`, `note()`, внизу сборка PDF-объектов.
- Режим КП: `unzip()`, `sheetImages()` (достаёт фото из xlsx), `looksKp()`, `parseKp()`.

Второй `<script>` (в IIFE): интерфейс.
- `parseWorkbook()` — разбор сметы аренды; `readGrid()` — значения ячеек для КП.
- `renderPaper()` / `renderKp()` — HTML-предпросмотр листа (должен совпадать с PDF по виду).
- `setMode()` — переключение «Смета аренды / КП с фото»; обработчик кнопки «Скачать PDF».
- `MYLOGO` — встроенный логотип RENTAL HUB (PNG base64).

Любая правка вида PDF делается в двух местах: в `buildPdf` (сам PDF) и в `renderPaper`/`renderKp` + CSS `.p-*`/`.k-*` (предпросмотр).

Единицы в PDF — пункты (pt), A4 = 595.28 × 841.89, поля M=42. В предпросмотре 1pt ≈ 1.333px, лист 794px.

Библиотека SheetJS грузится с cdnjs (`xlsx/0.18.5`). Больше внешних зависимостей нет.
